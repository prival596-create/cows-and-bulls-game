# Быки и Коровы — Telegram Mini App

Логическая игра: угадайте секретное число из уникальных цифр. Есть одиночный режим,
онлайн-комнаты с друзьями по коду и общий рейтинг.

## Что нового

- Сложность от 2 до 10 цифр.
- Ввод можно начинать с любой клетки: нажмите на неё, и цифры будут заполняться
  по порядку, по кругу. Повторное нажатие на заполненную клетку очищает её.
- Онлайн-игра идёт «до последнего»: когда все отгадали, комната закрывается,
  появляется финальная таблица, а последнее место получает случайный фант.
- Брошенные комнаты автоматически удаляются (при открытии приложения и создании
  новой комнаты).

## Стек

- React 18 + TypeScript + Vite
- Tailwind CSS
- Supabase (таблицы `global_scores`, `online_rooms`, `online_room_players`)
- Telegram WebApp SDK (`telegram-web-app.js`)

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # проверка типов
npm run lint
npm run build      # production-сборка в dist/
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `VITE_SUPABASE_URL` | да | URL проекта Supabase |
| `VITE_SUPABASE_ANON_KEY` | да | Публичный anon-ключ Supabase |
| `VITE_TELEGRAM_APP_LINK` | нет | Ссылка на мини-апп (`https://t.me/bot/app`) для кнопки «Поделиться» |

Без переменных Supabase приложение не запустится: `src/lib/supabase.ts` выбрасывает ошибку.
При публикации готовой папки `dist` переменные уже вшиты в сборку. Если подключать
Git-репозиторий к Netlify/Vercel, их нужно добавить в настройках проекта.

## Публикация (Netlify)

Самый простой путь для России — публиковать готовую папку `dist` через Netlify CLI.
GitHub для этого не обязателен (в 2026 году доступ к GitHub из России периодически
нестабилен, а сам сайт от GitHub не зависит).

Первый раз:

```bash
npx netlify-cli login
npx netlify-cli deploy --prod --dir=dist
```

`login` откроет браузер и попросит войти (можно по e-mail, без GitHub). При первом
`deploy` CLI предложит создать новый сайт — согласитесь. После деплоя он покажет
постоянный адрес вида `https://xxx.netlify.app`.

Обновления в дальнейшем:

```bash
npm run deploy
```

Это пересоберёт `dist` и зальёт новую версию на **тот же** адрес. Адрес в BotFather
менять не нужно.

Альтернатива без CLI: `app.netlify.com/drop` → перетащить папку `dist`. Но при
повторном drop создаётся новый сайт с новым адресом; обновлять нужно через
вкладку **Deploys** уже созданного сайта.

## Supabase

Миграция лежит в `supabase/migrations/`. Примените её к своему проекту:

```bash
supabase db push
```

Или выполните SQL вручную в Supabase → SQL Editor.

## Telegram

1. Создайте бота через `@BotFather` → `/newapp`, укажите URL задеплоенного сайта.
2. Откройте мини-апп из Telegram — SDK сам подтянет пользователя, тему и высоту экрана.
3. Для приглашений в комнату задайте `VITE_TELEGRAM_APP_LINK`.

## Плашка «Made in Bolt»

Плашка добавляется превью/хостингом Bolt, а не кодом приложения. На собственном хостинге
её нет. В проекте осталась только страховка:

- `src/lib/badge.ts` — точечно удаляет известные элементы плашки (без глобального
  удаления узлов и без таймера каждые 300 мс);
- `src/index.css` — CSS-правила только для селекторов плашки.

Удалены прежние «костыли», которые ломали вёрстку: `margin-bottom: -50px` у `body` и `#root`,
скрытие всех `div[style*="position: fixed"]` и удаление любых `body > div` с текстом `bolt.new`.
